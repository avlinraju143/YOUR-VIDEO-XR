# YOUR VIDEO XR

This is the first public-ready starter for YOUR VIDEO XR.

## Run locally
1. Install Node.js 20+.
2. Open this project folder in Terminal.
3. Run `npm install`
4. Run `npm start`
5. Open `http://localhost:3000`

## Important
This starter stores videos on the server filesystem and video metadata in memory. For a real public service, the next production phases should add:
- PostgreSQL or another persistent database
- Cloud video/object storage
- Authentication
- Creator profiles
- Comments/follows
- Admin moderation
- Report/block system
- Rate limiting and upload security
- HTTPS and domain
